ABOUT TKJ

WHAT IS TKJ?

Teknik Komputer dan Jaringan (TKJ) merupakan bidang keahlian yang mempelajari komputer, perangkat keras, sistem operasi, jaringan komputer, serta teknologi komunikasi data.

Melalui pembelajaran teori dan praktik, peserta didik mempelajari cara memahami, mengelola, dan memelihara sistem komputer serta jaringan.

CORE COMPETENCIES

WHAT YOU WILL LEARN

Berbagai bidang pengetahuan dalam Teknik Komputer dan Jaringan.

Computer Hardware

Mengenal komponen komputer, fungsi perangkat, dan perakitan komputer.

Computer Networking

Mempelajari konsep jaringan, topologi, LAN, MAN, dan WAN.

Operating System

Mengenal sistem operasi serta proses instalasi dan pengelolaannya.

Network Configuration

Memahami IP Address, gateway, DNS, dan konfigurasi jaringan.

Cybersecurity

Mengenal keamanan sistem, perlindungan data, dan kesadaran ancaman digital.

Programming

Mengenal dasar pemrograman, algoritma, HTML, CSS, dan JavaScript.
